# * projet git BDA latifa derouiche *
## description 
Ce projet est une application Python pour la gestion commerciale.

## Les programmes:
- marge.py : calcul de la marge commerciale.
- tva.py : calcul de la TVA et du prix TTC.
- interets.py : calcul des interets simples. 
- ventes.py : calcul du total des ventes.

## Le language utlisé:
python

## Utilisation:

Pour executer un programme, ouvrir le terminal et taper :

- python marge.py
- python tva.py
- python interets.py
- python ventes.py
